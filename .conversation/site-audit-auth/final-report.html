حوکمی کۆتایی

بەڵێ، دەتوانرێت سیستەمێکی نوێ بە هەمان شێوە و workflow دروست بکرێت و زۆر خێراتر بێت. ئەوە clone ـی source code نابێت؛ rebuild ـێکی پاک و نوێ دەبێت کە UI، زمان، فۆڕم، ژمێریاری، مەخزەن، پسووڵە و ڕاپۆرتەکان بە specification ـی ئەم پشکنینە دروست دەکات.

پشکنینەکە login و navigation بوو. هیچ دوگمەی پاشەکەوتکردن، زیادکردن، سڕینەوە، گەڕاندنەوە، ناردن، پشتڕاستکردنەوە یان چاپ کلیک نەکرا. URL ـە entity-specific ـەکان وەک customer یان invoice ـی جیاواز، بە template ـی نوێنەر پشکنران نەک بە کردنەوەی هەموو record ـەکان.

تەکنەلۆژیای ئێستا — پشتڕاستکراوە

  • ASP.NET Core + Blazor Server
  • Microsoft IIS 10 و SignalR/WebSocket لە /_blazor
  • MudBlazor + Fluent UI/Fabric + Bootstrap
  • Syncfusion PDF Viewer و Chart.js
  • CKEditor، jQuery و CryptoJS
  • Firebase Realtime Database scripts
  • Mapbox GL JS 3.10
  • Blazored Modal، Toaster و Infinite Scroll
  • Roboto و PFDinTextUniversal
  • Fabric icon font و barcode font
  • RTL Kurdish UI بە ٣ زمان: کوردی، عەرەبی، ئینگلیزی
  • Dark mode، fullscreen، favorites و global search
  • PDF/print، chart، file upload و image compression
  • Customer Portal login ـی جیاواز
  • TLS ـی Let's Encrypt و HSTS چالاک

tab و taxonomy ـە پشتڕاستکراوەکان

Dashboard: ٤ tabItem taxonomy: ١٢ tabAccount taxonomy: ٩ tabAccounting config: ٥ tabGeneral settings: ٥ tabAccount detail: ٣ tab

  • Dashboard: هێڵکاریەکان، پوختەی کاڵاکان، قەرزی خاوەن حساب، کارەکان.
  • Item taxonomy: جۆر، subtypes، brand، model، size، country، color، release date، attribute، version و sticker config.
  • Account taxonomy: city، type، پۆلێنی ١–٥، class و ownership type.
  • General settings: share ratio، currency، capital، system options و printing.
لە کۆتایی audit ـدا سێرڤەر HTTP/2/SignalR error ـی دا؛ بۆیە label و active content ـی سەرەتایی tab ـەکان تۆمار کرا، بەڵام هەموو tab ـەکان دووبارە کلیک نەکران. ئەمە دەبێت لە قۆناغی specification/UAT ـدا لەگەڵ کڕیار بە نموونەی data و print template تەواو بکرێت.

دیزاین و UX ـی ئێستا

  • top bar ـی شینی تۆخ، sidebar ـی icon-only لە ڕاست، content panel ـی سپی و RTL.
  • breadcrumb، back/next، currency، search، favorites، fullscreen، dark mode و profile/logout لە shell ـی هاوبەش.
  • card-based landing pages، tabs، dense data grids، sortable headers، filter/export/print controls.
  • فۆڕمەکان زۆربەیان panel ـی ڕەنگ‌کەم، field ـی ژمارەیی، date picker، select/autocomplete و sticky action ـیان هەیە.
  • Login ـی desktop دوو ستوونە؛ لە mobile وێنەی decorative دەشاردرێتەوە و horizontal overflow نییە.
  • lang="en" لەگەڵ Kurdish RTL ـە؛ لە وەشانی نوێدا metadata ـی زمان بە locale ـی ڕاست دادەنرێت.

تێبینییەکانی security

باشەکان

  • HTTPS و certificate ـی دروست
  • HSTS چالاک
  • Credential ـەکان لە فۆڕمی secret وەرگیران
  • هیچ write action ـێک لە audit نەکرا

پێویستی بە پشتڕاستکردنەوە

  • CSP / frame-ancestors
  • X-Content-Type-Options
  • Referrer-Policy و Permissions-Policy
  • Secure/HttpOnly/SameSite cookie flags
  • CSRF و per-record authorization
  • Role/workplace data isolation

Response ـی سەرەتایی IIS و ASP.NET ئاشکرا دەکات. ئەمە بە خۆی vulnerability نییە، بەڵام لە وەشانی نوێدا fingerprinting کەم دەکرێتەوە. دوای تەواوبوونی audit باشترە پاسۆردی ئەکاونتی بەکارهاتوو بگۆڕدرێت یان ئەکاونتی کاتی بسڕدرێتەوە.

داتا و شتانێک کە لە UI ـەوە نادیارن

لە UI ـەوە ناتوانرێت source code، database schema، stored procedure، هەموو business rule، permission enforcement و print calculation بە ١٠٠٪ دیاری بکرێت. بۆ clone ـی کاری تەواو، پێویستە دواتر یەکێک لەمانە بخرێتە بەردەست: schema/backup ـی پاککراو، API documentation، یان export ـی table ـەکان.
  • ڕێسای inventory costing و negative stock
  • ڕێسای currency conversion و rounding
  • invoice numbering، return/talaf و debt settlement
  • permission matrix بۆ هەر role/workplace
  • نمونەی PDF/print بۆ هەر جۆر پسووڵە و ڕاپۆرت
  • پلانی data migration: accounts، items، invoices، balances و attachments

پلانی دروستکردن

  1. Foundation: auth، roles، locale، shell، theme و database.
  2. Master data: workplace/warehouse، account، item/service و settings.
  3. Transactions: purchase، sale، returns، offers، payments، income/expense و debt.
  4. Inventory & accounting: transfers، stocktake، capital، profit/loss و balances.
  5. Reports & documents: filters، exports، PDF/print و customer portal.
  6. Migration & UAT: import، reconciliation، permission tests، load test و custom domain.
